#  EVENTIQUE🌻 – Event Management Website

### Creating Moments, Making Memories.

## 📌 About the Project

EVENTIQUE🌻 is a responsive event-management company website designed using HTML and CSS. It showcases different event-planning services, upcoming events, pricing packages, customer testimonials, team members, and contact information.

Our goal is to present a professional platform that helps people explore event services and plan their special occasions.

## 🎯 Project Objectives

- Design an attractive and user-friendly website.
- Display different event-management services.
- Showcase upcoming events and celebrations.
- Present affordable event packages.
- Build a professional brand identity.
- Create a responsive layout for different devices.

## ✨ Features

1. **Home:** Introduction to EVENTIQUE🌻.
2. **Our Services:** Wedding planning, birthday parties, corporate events, music festivals, college events, and decoration.
3. **Upcoming Events:** Event details, dates, locations, and images.
4. **Packages:** Silver, Gold, and Platinum plans.
5. **Testimonials:** Customer reviews and feedback.
6. **Our Team:** Introduction to team members.
7. **Contact:** Company contact information.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and layout.
- Google Fonts / System Fonts – Typography.
- Unsplash – Images.

## 🎨 Design Theme

- **Primary Colors:** Black and Gold.
- **Background:** Cream and Light Beige.
- **Style:** Modern, Elegant, and Professional.
- **Layout:** Responsive Grid and Flexbox.

## 🚀 How to Run

1. Download or copy the project files.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the webpage using Live Server or any web browser.
5. Explore the different sections of the website.

## 📱 Responsiveness

The website uses CSS media queries to adjust its layout for:
- Desktop computers
- Tablets
- Mobile phones
